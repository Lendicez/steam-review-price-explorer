# 已知限制

- 評論語言不是國籍，所選代表商店不是評論者實付地區；不可用此工具推論某國玩家評價。
- AppDetails 並非有長期相容承諾的正式價格 API。部分商店、成人內容、未發售或只有套件的 App 可能無價；不能據此斷言鎖區或下架。
- App 層級主要報價未逐一驗證區域套件內容。若資料未顯示版本差異，工具無法保證所有市場提供完全相同內容。
- 初次完整查詢需向上游讀取約 64 項資料；來源限流時會保留已完成結果，價格或評論各自顯示失敗。重新整理不繞過共用快取。
- 快取不是歷史資料庫。分享連結只保存條件；結果會隨時間更新。切換美國報價需整次重新整理，避免同表不同基準。
- 全語言獨立摘要與逐語言摘要可能因時間差或來源支援範圍不完全一致，介面顯示差額而不修改原始值。
- 匯率非銀行實際成交價，不校正稅制或付款費用。外匯發布時間超過 48 小時則停止換算。
- 此版本採 Vinext/Workers + D1，而非規格建議的 Express 單服務；Docker 僅提供本機 Worker 模擬。公開網站與完整原始碼已分開託管。
- 日期與資料僅代表測試／查詢當時，不應寫死遊戲評論數或售價。
